# year_project

## Исследование влияния области лёгких и технических артефактов на классификацию рентгенограмм
_Руководитель: Герасимова Мария_
_Состав команды: Полеонный Назар_
_Цель проекта — построить классификатор рентгенограмм и исследовать, какие области изображения модель использует для принятия решения._
Датасет: COVID-19 Radiography Database
задачи:
-исследовательский анализ изображений разных классов;
-проверка размеров, контрастности и качества снимков;
-поиск надписей, рамок и других технических артефактов;
-анализ дисбаланса классов;
-визуализация области лёгких;
-сравнение изображений до и после применения масок;
-поиск различий в источниках и способах подготовки изображений.
_ML/DL-задачи:_
-бинарная или многоклассовая классификация рентгенограмм;
-применение предобученных свёрточных нейронных сетей;
-сравнение моделей, обученных на полных изображениях и только на области лёгких;
-исследование влияния фона и технических артефактов;
-применение Grad-CAM и других методов интерпретации;
-оценка калибровки вероятностей;
-анализ уверенности модели на ошибочных примерах;
-исследование устойчивости к изменению контрастности, масштаба и качества изображения;
-проверка качества модели после искусственного удаления или добавления отдельных артефактов.

Чекпоинты
1. Знакомство с куратором, постановка и уточнение задачи, план на год
2. Изучение данных и EDA
3. Изучение существующих подходов для решения поставленной задачи и близких по формулировке; реализация бейзлайна (что-то максимально простое - быть может, даже ML)
4. Любое улучшение бейзлайна - реализация более сложного подхода из списка существующих или осуществление собственных идей
5. Создание сервиса с имплементацией лучшего ML-решения
6. Эксперименты с DL-архитектурами, выбор и тюнинг лучшей/лучших архитектур
7. Доработка задачи: улучшение сервисной части по обратной связи от команды курса по промышленной разработке
